# MHDB
Monster Hunter DataBase

## Purpose

This is the API documentation for the Monster Hunter DataBase Project. 

## Quickstart

- Build the project
```console
mage buildfull
```

- Run the project
```console
mage run
```

## Building the DB

You can build the DB seperately using 
```console
mage buiddb
```

This will rebuild the Database from scratch by transforming the data in the `/data/` folder.
